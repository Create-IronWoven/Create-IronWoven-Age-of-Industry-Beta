# Ironwoven: Age of Industry — v0.1.110-R002

## Feedback

Before reporting a problem, check [Known Issues](KNOWN_ISSUES.md) and search the [issue tracker](../../issues). Include reproduction steps, Minecraft/NeoForge versions, and the modpack build if one was provided.

Remove usernames, private addresses, local paths, passwords, tokens, and personal information from logs or screenshots. Do not upload world saves, private backups, or third-party mod JARs.

A successful server startup does not prove every mod feature works. The [testing checklist](TESTING_CHECKLIST.md) separates startup checks from individual feature validation. Testers can submit one action at a time using the [Functional Test Result form](https://github.com/alexth110987/Create-IronWoven-Beta/issues/new?template=functional-test-report.yml). Each report records whether the action was tested in Single-player, Multiplayer, or Both. Once the repository's one-time Actions write permission is configured, successful submissions update the matching checklist row automatically; no Markdown editing is required.
