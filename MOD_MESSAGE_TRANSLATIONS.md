# Mod Message Translations

This page translates non-English messages found in Create IronWoven mod logs or screenshots so the maintainer and public readers can understand them.

A mod's own messages do not have to be in English. Language notes are informational and are not compatibility failures or reasons to reject a mod. Technical issues are documented separately.

## Translation record

### Create Aeronautics Structures 1.1.0-Beta-3.1

- **Minecraft / loader:** Minecraft 1.21.1 · NeoForge 21.1.265
- **Evidence date:** 5 November 2026
- **Where it appeared:** Dedicated-server startup log
- **Original language:** Russian
- **Original text:** Мод Create Aeronautics Structures загружается!
- **English translation:** “Create Aeronautics Structures is loading!”
- **What it means:** This is an informational startup message saying that Create Aeronautics Structures is loading.
- **Compatibility status:** The Russian wording is not a problem and does not block acceptance. The separate loot-table parsing error and outstanding file/generation checks are tracked in the [testing checklist](TESTING_CHECKLIST.md) and [beta status](BETA_STATUS.md).

## How future translations are added

When a non-English message appears in a log or screenshot, the original wording and an English translation will be added here, with the mod name, version when known, and context. Ambiguous translations will be marked as approximate. Language notes will be kept separate from technical compatibility findings.
