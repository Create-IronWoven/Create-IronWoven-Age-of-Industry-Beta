# Player Feedback and Contributions

Thanks for helping test Ironwoven: Age of Industry.

## Feedback

Use GitHub Issues to submit:
- Bugs and crashes
- Dedicated-server or multiplayer compatibility issues
- Mod conflicts
- Performance problems
- Suggestions for features, mods, or balance

Choose the closest issue form and provide as much detail as you can. Search existing issues first so reports can be discussed in one place.

## Good bug reports

A useful report explains:
- What you expected to happen.
- What actually happened.
- How to reproduce it.
- Whether it happens every time.
- Which game and modpack versions you used.

Screenshots and short log excerpts can help. Remove personal details before attaching them.

## Scope

This is a player feedback repository, not the pack's source code repository. Please do not submit mod JARs, world saves, private configs, or large log bundles. Feature suggestions are welcome, but not every suggestion will be accepted.
