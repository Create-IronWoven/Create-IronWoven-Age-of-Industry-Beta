This repository is for public beta feedback, not security-sensitive reports.

Do not post passwords, access tokens, private server addresses, personal data, or exploitable security details in public issues. Do not upload private backups or full world folders.

For ordinary gameplay bugs, use the public issue templates. For sensitive security concerns, contact the maintainer privately through a trusted channel rather than opening a public issue.
