# Historical test-folder inventory snapshot — preserved 11 November 2026

This file preserves the dated test-folder inventory tables and notes formerly embedded in the public `MODS.md`. These records remain available for historical comparison and troubleshooting, but they are **not** the current active mod-set list, a complete current client/server inventory, or a release manifest.

Use [current MODS.md](../MODS.md) for current accepted mod-set status and outstanding profile rechecks. The latest complete 10 November file-level profile inventory is retained in the private development repository; it is not copied into this public archive.

The tables below preserve earlier folder observations and should be read as dated evidence only. They do not establish the exact current installed inventory, accepted status, or release eligibility.
