# Privacy Review — Upstream Fix Contributions

**Review scope:** files under `contributions/upstream-fixes/` in this repository.

## Publication checks

- [x] No local Windows, Linux, or macOS filesystem paths.
- [x] No local usernames, machine names, or account identifiers in document content.
- [x] No private repository names, private repository links, or private commit references.
- [x] No private server names, world names, save names, or player data.
- [x] No raw game logs, debug logs, screenshots, crash reports, or uploaded attachments.
- [x] No passwords, access tokens, API keys, or other credentials.
- [x] No mod JARs, compiled binaries, resource packs, or copied asset collections.
- [x] Links point only to public upstream repositories, issues, pull requests, or source files.
- [x] Proposed changes are limited to small text diffs; no full upstream source files are republished.

## Limits

This checklist documents a review of the new contribution folder only. It is not a forensic secret scan of the repository's complete Git history, external services, or previously published files. Existing player-facing repository documents were not rewritten as part of this contribution-folder change.

The reports describe technical findings at a general compatibility level and omit private test-environment identifiers and local reproduction paths.
