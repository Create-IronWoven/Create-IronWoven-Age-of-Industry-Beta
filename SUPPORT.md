# Support and Troubleshooting

## Before asking for help

1. Confirm that you are using the Minecraft and NeoForge versions required by the beta build you installed.
2. Check that the client and server use matching modpack versions.
3. Restart the game once and see whether the issue repeats.
4. Check [Known Issues](KNOWN_ISSUES.md).
5. Search existing reports in the [issue tracker](../../issues).

## What to include in a support report

- The exact modpack build or release name.
- Minecraft version and NeoForge version.
- Whether the problem happens in single-player or on a dedicated server.
- What you were doing immediately before the problem.
- Steps that reproduce it.
- Relevant error text or a short, privacy-cleaned log excerpt.

## Logs and privacy

Logs can contain usernames, local file paths, server addresses, and other identifying details. Read through files before posting them. Remove passwords, access tokens, private addresses, and information you do not want public.

Do not upload entire world folders or private server backups. A short relevant excerpt is usually enough.
